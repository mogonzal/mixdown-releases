# Mixdown

A professional dual-deck DJ application.

## Download

Go to the [latest release](https://github.com/mogonzal/mixdown-releases/releases/latest) and download the installer for your platform:

| Platform | File |
|----------|------|
| macOS (Apple Silicon) | `Mixdown-{version}-arm64.dmg` |
| macOS (Intel) | `Mixdown-{version}-x64.dmg` |
| Windows (x64) | `Mixdown-{version}-x64.exe` |

## System Requirements

- macOS 12+ (Apple Silicon or Intel)
- Windows 10/11 (x64)
